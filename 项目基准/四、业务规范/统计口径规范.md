# 统计口径规范

> 状态：已确认

## 目的
统一定义统计指标的计算方式，确保数据一致性。

## 适用范围
所有统计相关的页面和 API。

## 规范内容

### 个人统计指标

| 指标 | 计算方式 | 说明 |
|---|---|---|
| 总打卡天数 | `count(检查in where userId = X and status = 'PUBLISHED')` | 去重按日期计数 |
| 当前连续天数 | 从今天往前数，连续打卡天数 | 使用 `calculateStreak` |
| 最长连续天数 | 历史最大连续天数 | 需要遍历所有打卡记录 |
| 总单词数 | `sum(wordCount) where userId = X and status = 'PUBLISHED'` | 所有打卡的单词数总和 |
| 平均每日单词 | `totalWords / totalDays` | 总单词数 / 总打卡天数 |
| 平均每日用时 | `sum(minutes) / totalDays` | 总用时 / 总打卡天数 |
| 本周打卡 | `count where date >= 本周开始 and userId = X` | 本周一到周日 |
| 本月打卡 | `count where date >= 本月开始 and userId = X` | 本月1日到今天 |

### 圈子统计指标

| 指标 | 计算方式 | 说明 |
|---|---|---|
| 圈子总打卡数 | `count where circleId = X and status = 'PUBLISHED'` | 圈子内所有打卡 |
| 成员平均打卡 | `totalCheckins / memberCount` | 总打卡 / 成员数 |
| 活跃成员 | `count(distinct userId where date >= 7天前)` | 近7天有打卡的成员 |
| 周榜排名 | 按本周打卡数排名 | 使用 WeeklySnapshot |
| 总单词数 | `sum(wordCount) where circleId = X` | 圈子总学习量 |

### 排行榜
- 周期：每周（周一到周日）
- 排名依据：本周打卡天数 > 本周单词数 > 本周用时
- 快照生成：每周日凌晨生成 WeeklySnapshot

### 时区处理
- 所有日期计算使用圈子时区（默认 `Asia/Shanghai`）
- 打卡日期存储在 `Checkin.date` 字段
- 使用 `date-fns` + `@date-fns/tz` 处理

## 禁止事项
- 禁止不同页面使用不同的统计口径
- 禁止在前端计算统计数据（必须在后端）
- 禁止统计时忽略时区
- 禁止在排行中忽略已撤回的打卡
