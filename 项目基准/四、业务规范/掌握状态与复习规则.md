# 掌握状态与复习规则

> 状态：草案

## 目的
定义单词掌握状态的判定标准和复习提醒规则。

## 适用范围
词库模块、打卡模块。

## 规范内容

### 掌握状态定义

| 状态 | 英文 | 说明 |
|---|---|---|
| 新词 | NEW | 首次出现的单词，未学习 |
| 学习中 | LEARNING | 正在学习中的单词 |
| 复习中 | REVIEWING | 需要复习的单词 |
| 已掌握 | MASTERED | 已经掌握的单词 |

### 状态转换规则
```
NEW → LEARNING      （首次打卡包含该单词）
LEARNING → REVIEWING （打卡次数 >= 3 但未连续掌握）
LEARNING → MASTERED （连续打卡 7 天包含该单词）
REVIEWING → LEARNING （复习打卡失败）
REVIEWING → MASTERED （复习打卡成功）
```

### 复习提醒
- 基于间隔重复算法（简化版 SRS）
- 新词：下次复习 = 打卡日期 + 1 天
- 学习中：下次复习 = 上次复习 + 3 天
- 复习中：下次复习 = 上次复习 + 7 天
- 已掌握：不再提醒

### 数据统计
- 掌握率 = `MASTERED 单词数 / 总单词数 * 100%`
- 平均复习周期：所有单词的复习间隔平均值

## 禁止事项
- 禁止手动修改掌握状态（除管理员修正外）
- 禁止在单词被标记为已掌握后仍出现在"新词"推荐中
- 禁止忽略时区计算复习日期
