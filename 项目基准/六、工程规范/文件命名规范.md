# 文件命名规范

> 状态：已确认

## 目的
规范文件的命名方式，确保命名一致、易理解。

## 适用范围
所有代码文件、配置文件、文档文件。

## 规范内容

### 文件命名规则

| 类型 | 约定 | 示例 |
|---|---|---|
| 代码文件 | kebab-case | `checkin.service.ts` |
| React 组件 | PascalCase（文件名 kebab-case） | `CheckinForm` → `checkin-form.tsx` |
| 配置文件 | kebab-case | `tailwind.config.ts` |
| 测试文件 | 原文件名 + `.test.ts` | `stats.service.test.ts` |
| 文档文件 | 中文名称 + `.md` | `术语定义.md` |
| 类型文件 | kebab-case + `.d.ts` | `global.d.ts` |

### React 组件命名
- 组件导出：PascalCase
- 文件命名：kebab-case
- 文件名与组件名对应

```tsx
// checkin-form.tsx
export function CheckinForm() { ... }
```

### 数据库文件
- Schema：`schema.prisma`
- 迁移：`YYYYMMDDHHMMSS_description/migration.sql`
- 种子：`seed.ts`

### 图片文件
- 命名：kebab-case
- 扩展名：根据实际格式（`.png`, `.jpg`, `.svg`）
- 图标：`icon-192.png`

## 禁止事项
- 禁止使用中文命名代码文件
- 禁止使用空格命名文件
- 禁止使用特殊字符命名文件
- 禁止文件名与内容无关
