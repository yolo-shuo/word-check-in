# 数据字段命名规范

> 状态：已确认

## 目的
规范数据库字段和 TypeScript 类型的命名方式，确保命名一致。

## 适用范围
所有数据库模型、TypeScript 类型、API 字段。

## 规范内容

### 命名规则

| 类型 | 约定 | 示例 |
|---|---|---|
| 数据库表 | snake_case | `checkin_edits` |
| 数据库字段 | camelCase | `wordCount`, `createdAt` |
| TypeScript 类型 | PascalCase | `type CheckinInput` |
| 接口/类型 | PascalCase | `interface UserProps` |
| 枚举值 | SCREAMING_SNAKE_CASE | `PUBLISHED`, `WITHDRAWN` |
| 常量 | SCREAMING_SNAKE_CASE | `MAX_WORD_COUNT` |

### Prisma Schema 约定
- 所有 model 必须有 `id` 字段（cuid）
- 所有 model 必须有 `createdAt`（默认 `now()`）
- 可更新的 model 必须有 `updatedAt`（默认 `@updatedAt`）
- 可删除的实体必须有 `deletedAt` 字段（DateTime?）
- 枚举使用 `enum` 关键字，值使用 SCREAMING_SNAKE_CASE
- 关系必须使用 `@relation(fields: [...], references: [...])`

### 字段命名示例
```prisma
model Checkin {
  id        String        @id @default(cuid())
  circleId  String
  userId    String
  wordCount Int
  date      DateTime      @db.Date
  status    CheckinStatus @default(PUBLISHED)
  deletedAt DateTime?
  createdAt DateTime      @default(now())
  updatedAt DateTime      @updatedAt
}
```

### 常用字段
- `id`：主键
- `createdAt`：创建时间
- `updatedAt`：更新时间
- `deletedAt`：软删除时间
- `circleId`：圈子 ID
- `userId`：用户 ID

## 禁止事项
- 禁止数据库字段使用 PascalCase
- 禁止 TypeScript 类型使用 snake_case
- 禁止枚举值使用 camelCase
- 禁止缺少 `createdAt` 字段
- 禁止直接使用 `Date` 类型（使用 `DateTime`）
