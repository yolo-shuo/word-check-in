# 测试规范

> 状态：已确认

## 目的
规范测试的类型、结构和标准，确保代码质量。

## 适用范围
所有测试代码。

## 规范内容

### 测试类型

| 类型 | 工具 | 文件位置 | 说明 |
|---|---|---|---|
| 单元测试 | Vitest | `*.test.ts` | 测试单个函数/组件 |
| 集成测试 | Vitest + Prisma | `*.integration.test.ts` | 测试模块集成 |
| E2E 测试 | Playwright | `tests/e2e/` | 测试完整用户流程 |

### 单元测试规范
- 每个 service 函数对应一个测试文件
- 使用 `vi.mock()` mock 外部依赖
- 测试文件命名：`*.test.ts`
- 每个测试用例独立，不依赖其他用例

```tsx
import { describe, it, expect, vi } from 'vitest'
import { calculateStreak } from './stats.service'

describe('calculateStreak', () => {
  it('should return 0 for empty dates', () => {
    expect(calculateStreak(new Set())).toBe(0)
  })

  it('should return 1 for single day', () => {
    expect(calculateStreak(new Set(['2024-01-01']))).toBe(1)
  })
})
```

### 集成测试规范
- 使用测试数据库（不污染开发数据）
- 每个测试前清空数据
- 使用事务回滚（可选）

### E2E 测试规范
- 使用 Playwright
- 测试关键路径：登录 → 建圈 → 打卡 → 点赞 → 评论 → 导出
- 测试文件位置：`tests/e2e/`
- 运行命令：`npx playwright test`

### 测试覆盖率要求
- 核心业务逻辑：> 80%
- 工具函数：> 90%
- UI 组件：> 50%
- E2E 覆盖关键路径

## 禁止事项
- 禁止提交无测试的 Bug 修复
- 禁止测试依赖外部服务（使用 mock）
- 禁止在测试中写业务逻辑
- 禁止测试之间共享状态
- 禁止提交测试失败的代码
