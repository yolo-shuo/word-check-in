# 目录结构规范

> 状态：已确认

## 目的
规范项目的目录结构，确保代码组织清晰、易维护。

## 适用范围
整个项目代码目录。

## 规范内容

### 目录结构

```
word-check-in/
├── prisma/                    # 数据库相关
│   ├── schema.prisma          # Prisma Schema
│   ├── migrations/            # 数据库迁移文件
│   └── seed.ts                # 种子数据
├── src/
│   ├── app/                   # Next.js App Router
│   │   ├── (auth)/            # 登录/注册
│   │   ├── (circle)/          # 圈子功能
│   │   ├── api/               # API 路由
│   │   ├── layout.tsx         # 根布局
│   │   └── page.tsx           # 首页（重定向）
│   ├── server/                # 服务端
│   │   ├── routers/           # tRPC 路由
│   │   ├── services/          # 业务服务
│   │   ├── lib/               # 服务端工具
│   │   ├── prisma.ts          # Prisma 客户端
│   │   ├── trpc.ts            # tRPC 初始化
│   │   └── auth.ts            # NextAuth 配置
│   ├── components/            # React 组件
│   │   ├── ui/                # shadcn/ui 组件
│   │   ├── checkin/           # 打卡相关组件
│   │   ├── feed/              # 动态相关组件
│   │   ├── stats/             # 统计相关组件
│   │   ├── vocab/             # 词库相关组件
│   │   └── shared/            # 通用组件
│   ├── lib/                   # 客户端工具
│   └── types/                 # 共享类型
├── public/                    # 静态文件
├── tests/                     # 测试文件
│   ├── e2e/                   # E2E 测试
│   └── unit/                  # 单元测试
├── docker-compose.yml         # Docker Compose
├── Dockerfile                 # Docker 构建
├── .env.example               # 环境变量示例
├── tsconfig.json              # TypeScript 配置
├── tailwind.config.ts         # Tailwind 配置
├── vitest.config.ts           # Vitest 配置
└── package.json
```

### 目录规则
1. `src/app/`：Next.js 路由页面
2. `src/server/`：服务端代码（仅服务端使用）
3. `src/components/`：共享组件
4. `src/lib/`：客户端工具函数
5. `src/types/`：共享类型定义
6. 按功能模块组织组件目录

### 导入路径
- 使用 `@/` 别名引用 `src/` 下的文件
- 不使用相对路径跨目录引用

## 禁止事项
- 禁止在服务端代码中使用客户端 API
- 禁止在客户端代码中导入服务端模块
- 禁止在 `src/app/` 下编写业务逻辑
- 禁止在 `node_modules` 外随意放置文件
