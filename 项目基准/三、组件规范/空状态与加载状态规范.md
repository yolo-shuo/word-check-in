# 空状态与加载状态规范

> 状态：已确认

## 目的
规范页面在不同状态下的显示方式，提供一致的用户体验。

## 适用范围
所有列表页面、数据展示页面。

## 规范内容

### 状态类型

| 状态 | 组件 | 说明 |
|---|---|---|
| 加载中 | `<LoadingState />` | 居中旋转图标 + 文字 |
| 加载错误 | `<ErrorState />` | 错误图标 + 信息 + 重试按钮 |
| 空数据 | `<EmptyState />` | 空状态图标 + 提示文字 |

### LoadingState
```tsx
<LoadingState text="加载中..." />

// Props
interface LoadingStateProps {
  text?: string  // 默认 "加载中..."
  height?: string  // 自定义高度，默认 "100%"
}
```

### ErrorState
```tsx
<ErrorState
  message="加载失败"
  hint="请检查网络连接"
  onRetry={retry}
/>

// Props
interface ErrorStateProps {
  message: string
  hint?: string
  onRetry?: () => void
  height?: string
}
```

### EmptyState
```tsx
<EmptyState
  icon={<Inbox size={48} />}
  title="暂无数据"
  description="还没有打卡记录，快去创建第一条吧！"
/>

// Props
interface EmptyStateProps {
  icon?: React.ReactNode
  title: string
  description?: string
  height?: string
}
```

### 使用规则
1. 所有列表页面必须处理三种状态
2. 加载状态显示在内容区域上方
3. 空状态在确认无数据时显示
4. 错误状态必须提供重试方式

## 示例
```tsx
export function Checklist() {
  const { data, isLoading, isError, error, refetch } = useQuery(...)

  if (isLoading) return <LoadingState />
  if (isError) return <ErrorState message="加载失败" onRetry={refetch} />
  if (data.length === 0) {
    return (
      <EmptyState
        icon={<Calendar size={48} />}
        title="暂无打卡记录"
        description="从今天开始，记录你的学习吧！"
      />
    )
  }

  return <CheckinList items={data} />
}
```

## 禁止事项
- 禁止在加载中显示空列表
- 禁止错误状态不提供重试
- 禁止空状态只显示图标无文字
- 禁止在不同页面使用不同的空状态样式
