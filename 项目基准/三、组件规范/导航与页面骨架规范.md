# 导航与页面骨架规范

> 状态：已确认

## 目的
规范应用的导航结构和页面骨架，确保导航体验一致。

## 适用范围
所有页面的导航组件和布局骨架。

## 规范内容

### 导航结构

```
├── 顶部导航栏 (Navbar)
│   ├── Logo / 应用名称
│   ├── 导航链接
│   │   ├── 动态流 (/feed)
│   │   ├── 打卡 (/checkin)
│   │   ├── 统计 (/stats)
│   │   ├── 词库 (/vocab)
│   │   ├── 成员 (/members)
│   │   └── 设置 (/settings)
│   ├── 圈子选择器
│   ├── 通知铃铛
│   └── 用户菜单
│
└── 移动端底部 Tab
    ├── 动态
    ├── 打卡
    ├── 统计
    └── 我的
```

### 导航栏组件
```tsx
<Navbar />  // src/components/layout/navbar.tsx
```

### 圈子导航
```tsx
<CircleNav />  // src/components/circle-nav.tsx
```

### 面包屑
```tsx
<Breadcrumb
  items={[
    { title: "圈子", href: "/feed" },
    { title: "打卡详情" },
  ]}
/>
```

### 布局要求
- 所有页面必须使用统一的 layout.tsx
- 导航栏固定在顶部
- 内容区域有最小高度
- 页面切换时保留滚动位置（可选）

### 导航状态
- 当前页面高亮
- 加载中状态可显示骨架屏（可选）
- 移动端导航收起为 Tab 栏

## 示例
```tsx
// 页面中使用导航
import { CircleNav } from '@/components/circle-nav'
import { Breadcrumb } from '@/components/breadcrumb'

export default function Page() {
  return (
    <div>
      <Breadcrumb items={[{ title: "首页", href: "/" }, { title: "当前页" }]} />
      {/* 页面内容 */}
    </div>
  )
}
```

## 禁止事项
- 禁止在页面内自定义导航结构
- 禁止导航项文字不一致
- 禁止移动端导航不可点击
- 禁止导航栏高度不一致
