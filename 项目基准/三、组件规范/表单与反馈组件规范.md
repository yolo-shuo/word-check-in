# 表单与反馈组件规范

> 状态：已确认

## 目的
规范表单组件的使用方式、验证逻辑和错误反馈，确保表单交互一致。

## 适用范围
所有包含表单的页面（打卡创建、注册、设置等）。

## 规范内容

### 表单库
- 使用 `react-hook-form` + `zod` 进行表单管理和验证
- 表单提交必须经过 zod schema 验证

### 表单结构
```tsx
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

const schema = z.object({
  wordCount: z.number().min(1).max(2000),
  minutes: z.number().min(1).max(720),
  note: z.string().max(300).optional(),
})

const form = useForm({
  resolver: zodResolver(schema),
  defaultValues: { wordCount: 0, minutes: 0 },
})
```

### 表单字段
- 标签：使用 `<Label />` 组件
- 输入框：使用 `<Input />` 组件
- 错误提示：红色文字显示在字段下方
- 必填标记：标签后加 `*`

### 表单按钮
- 提交按钮：主要按钮，加载中显示 loading 状态
- 取消按钮：次要按钮
- 按钮间距：`gap-3`

### 错误反馈
- 字段错误：显示在对应字段下方
- 提交错误：显示在表单顶部
- 网络错误：使用 toast 或错误状态

## 示例
```tsx
<form onSubmit={form.handleSubmit(onSubmit)}>
  <div className="space-y-4">
    <div>
      <Label htmlFor="wordCount">单词数 *</Label>
      <Input
        id="wordCount"
        type="number"
        {...form.register('wordCount')}
      />
      {form.formState.errors.wordCount && (
        <p className="text-red-500 text-sm mt-1">
          {form.formState.errors.wordCount.message}
        </p>
      )}
    </div>

    <div className="flex gap-3">
      <Button type="submit" disabled={form.formState.isSubmitting}>
        {form.formState.isSubmitting ? '提交中...' : '提交'}
      </Button>
      <Button type="button" variant="outline">取消</Button>
    </div>
  </div>
</form>
```

## 禁止事项
- 禁止手动验证表单（必须使用 zod）
- 禁止在组件中硬编码验证规则
- 禁止使用受控组件（除特殊需求外）
- 禁止提交时不显示加载状态
