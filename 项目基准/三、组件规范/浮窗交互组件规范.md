# 浮窗交互组件规范

> 状态：已确认

## 目的
规范弹窗、下拉菜单、通知等浮层组件的使用方式和交互风格。

## 适用范围
所有需要浮层交互的页面和组件。

## 规范内容

### 浮层类型

| 类型 | 组件 | 用途 |
|---|---|---|
| 确认对话框 | `<ConfirmDialog />` | 删除确认、操作确认 |
| 下拉菜单 | 自定义 | 操作菜单、选项选择 |
| 模态框 | 自定义 | 表单弹窗、详情弹窗 |
| Toast 通知 | 自定义 | 操作反馈、错误提示 |

### ConfirmDialog
```tsx
<ConfirmDialog
  open={isConfirmOpen}
  onOpenChange={setIsConfirmOpen}
  title="确认删除"
  description="删除后无法恢复，确定要删除吗？"
  confirmLabel="删除"
  cancelLabel="取消"
  onConfirm={handleDelete}
  variant="destructive"
/>
```

### 下拉菜单
- 使用 `dropdown-menu` 组件
- 菜单项必须包含图标（可选）
- 危险操作使用红色文字
- 菜单项间距：`py-2 px-3`

### Toast 通知
- 成功：`toast({ title: "操作成功" })`
- 错误：`toast({ title: "操作失败", variant: "destructive" })`
- 自动关闭时间：3 秒
- 位置：右上角

### 模态框
- 宽度：`max-w-md` 或 `max-w-lg`
- 标题必须存在
- 必须有关闭按钮
- 遮罩点击关闭（可选）

## 示例
```tsx
// 正确：确认删除
<Button variant="destructive" onClick={() => setConfirmOpen(true)}>
  删除
</Button>

<ConfirmDialog
  open={confirmOpen}
  onOpenChange={setConfirmOpen}
  title="确认删除"
  description="删除后无法恢复，确定要删除吗？"
  confirmLabel="删除"
  onConfirm={async () => {
    await deleteItem(id)
    toast({ title: "删除成功" })
  }}
/>
```

## 禁止事项
- 禁止使用 `window.confirm` 或 `window.alert`
- 禁止弹窗内使用内联样式
- 禁止模态框无标题
- 禁止 toast 超过 5 秒不自动关闭
