# 图标使用规范

> 状态：已确认

## 目的
统一图标的使用方式、来源和尺寸，确保视觉一致性。

## 适用范围
所有需要显示图标的页面和组件。

## 规范内容

### 图标库
- 使用 `lucide-react` 图标库
- 统一从 `lucide-react` 导入

### 图标尺寸
| 场景 | 尺寸 | 使用方式 |
|---|---|---|
| 导航图标 | 20px | `<Home size={20} />` |
| 按钮图标 | 16px | `<Send size={16} />` |
| 列表图标 | 20px | `<BookOpen size={20} />` |
| 空状态图标 | 48px | `<Inbox size={48} />` |
| 小图标 | 14px | `<Check size={14} />` |

### 图标颜色
- 跟随文字颜色：`className="text-current"`
- 固定颜色时通过 `stroke` 属性设置
- 禁止使用图标内置颜色

### 图标语义
| 图标 | 用途 |
|---|---|
| Home | 首页/动态流 |
| Calendar | 打卡/日期 |
| Users | 成员管理 |
| BarChart3 | 统计 |
| BookOpen | 词库 |
| Settings | 设置 |
| Bell | 通知 |
| Shield | 管理/审计 |
| Plus | 新建 |
| Edit / Pencil | 编辑 |
| Trash2 | 删除 |
| Heart | 点赞 |
| MessageCircle | 评论 |

## 示例
```tsx
import { Home, Calendar } from 'lucide-react'

// 正确：带图标按钮
<button className="flex items-center gap-2">
  <Calendar size={16} />
  打卡
</button>

// 错误：使用字符串而非组件
<span className="icon-calendar">📅</span>
```

## 禁止事项
- 禁止混用多个图标库
- 禁止使用 emoji 代替图标
- 禁止使用未定义的图标尺寸
- 禁止在图标上添加自定义 CSS 样式
