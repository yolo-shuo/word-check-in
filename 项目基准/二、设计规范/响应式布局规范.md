# 响应式布局规范

> 状态：已确认

## 目的
确保应用在不同屏幕尺寸下都能正常显示和操作。

## 适用范围
所有页面和组件。

## 规范内容

### 断点定义
使用 Tailwind 内置断点：

| 断点 | 宽度 | 设备 |
|---|---|---|
| `sm` | 640px | 大手机 |
| `md` | 768px | 平板 |
| `lg` | 1024px | 桌面 |
| `xl` | 1280px | 大屏桌面 |

### 布局策略
1. **移动优先**：先设计移动端，再逐步增加桌面端样式
2. **弹性布局**：使用 Flexbox 和 Grid 布局
3. **最大宽度**：内容区域使用 `max-w-*` 限制宽度

### 页面布局
- 移动端：单列布局
- 桌面端：多列布局（`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`）
- 页面内边距：`px-4 md:px-6 lg:px-8`

### 导航
- 移动端：底部 Tab 或汉堡菜单
- 桌面端：顶部导航栏

### 表格
- 移动端：卡片列表
- 桌面端：表格视图

## 示例
```tsx
// 正确：移动优先
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  {/* 内容 */}
</div>

// 错误：桌面优先
<div className="grid-cols-3 md:grid-cols-2 lg:grid-cols-1 gap-4">
  {/* 内容 */}
</div>
```

## 禁止事项
- 禁止固定宽度布局（使用百分比或 flex/grid）
- 禁止在小屏幕上显示过多元素
- 禁止触摸目标小于 44x44px
- 禁止在移动端使用 hover 效果
