# 主题与暗色模式规范

> 状态：草案

## 目的
支持暗色模式，确保用户在暗色环境下的使用体验。

## 适用范围
所有页面和组件。

## 规范内容

### 当前状态
- 暂不支持暗色模式
- 仅支持亮色模式
- 后续版本计划添加暗色模式支持

### 暗色模式实现计划
1. 使用 CSS 变量定义颜色主题
2. 通过 `class` 或 `data-theme` 切换主题
3. 支持系统偏好和手动切换
4. 使用 `next-themes` 库管理

### 颜色变量（计划）
```css
:root {
  --background: #ffffff;
  --foreground: #1f2937;
  --primary: #3b82f6;
  --border: #e5e7eb;
}

.dark {
  --background: #111827;
  --foreground: #f9fafb;
  --primary: #60a5fa;
  --border: #374151;
}
```

## 禁止事项
- 禁止在组件中硬编码颜色值（应使用 CSS 变量或 Tailwind 类）
- 禁止在计划阶段修改暗色模式相关代码
