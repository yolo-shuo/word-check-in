# 页面模板规范

> 状态：已确认

## 目的
定义标准页面模板，减少重复开发，确保页面结构一致。

## 适用范围
所有页面组件。

## 规范内容

### 标准页面结构

```tsx
export default function PageName() {
  return (
    <div className="p-4 md:px-6 lg:px-8 py-6">
      {/* 页面标题 */}
      <h1 className="text-2xl font-bold mb-6">页面标题</h1>

      {/* 页面内容 */}
      <div className="max-w-3xl mx-auto">
        {/* 内容区域 */}
      </div>
    </div>
  )
}
```

### 页面类型

| 类型 | 结构 | 示例 |
|---|---|---|
| 列表页 | 标题 + 筛选 + 列表 | 动态流、打卡列表 |
| 表单页 | 标题 + 表单 + 提交 | 打卡创建、设置 |
| 详情页 | 标题 + 信息 + 操作 | 打卡详情 |
| 空状态页 | 居中图标 + 文字 | 无数据时 |

### 列表页模板
```tsx
<div className="p-4 md:px-6 lg:px-8 py-6">
  <h1 className="text-2xl font-bold mb-6">列表标题</h1>

  {/* 筛选/搜索 */}
  <div className="mb-4 flex gap-2">
    {/* 筛选组件 */}
  </div>

  {/* 列表 */}
  <div className="space-y-3">
    {items.map(item => <Card key={item.id} />)}
  </div>

  {/* 空状态 */}
  {items.length === 0 && <EmptyState />}

  {/* 加载状态 */}
  {isLoading && <LoadingState />}
</div>
```

### 表单页模板
```tsx
<div className="p-4 md:px-6 lg:px-8 py-6 max-w-xl mx-auto">
  <h1 className="text-2xl font-bold mb-6">表单标题</h1>

  <form onSubmit={handleSubmit}>
    <div className="space-y-4">
      {/* 表单字段 */}
    </div>

    <div className="mt-6 flex gap-3">
      <Button type="submit">提交</Button>
      <Button variant="outline">取消</Button>
    </div>
  </form>
</div>
```

## 禁止事项
- 禁止在页面中直接写复杂业务逻辑（使用组件/服务）
- 禁止在页面中直接查询数据库（使用 tRPC 或 API）
- 禁止页面超过 300 行代码（考虑拆分组件）
