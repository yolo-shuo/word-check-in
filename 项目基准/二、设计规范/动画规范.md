# 动画规范

> 状态：已确认

## 目的
规范项目中动画的使用方式、时长和触发条件，确保体验流畅一致。

## 适用范围
所有需要动画效果的页面和组件。

## 规范内容

### 动画时长
| 类型 | 时长 | 缓动函数 |
|---|---|---|
| 悬停效果 | 150ms | ease |
| 展开/收起 | 200ms | ease-in-out |
| 页面切换 | 300ms | ease-in-out |
| 模态框 | 250ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 加载指示器 | 持续循环 | linear |

### 动画类型
- **过渡**：`transition` 用于 hover、focus 等状态变化
- **关键帧**：`@keyframes` 用于加载旋转、脉冲等循环动画
- **弹性动画**：仅在需要特殊效果时使用，避免过度使用

### 使用原则
1. 动画必须服务于功能，不能为了炫技而添加
2. 必须尊重 `prefers-reduced-motion` 媒体查询
3. 禁用动画时不影响功能使用
4. 动画不能阻塞用户交互

## 示例
```tsx
// 正确：使用 Tailwind transition
<button className="transition-colors duration-150 ease-in">
  Hover me
</button>

// 正确：尊重 prefers-reduced-motion
const motionStyle = useMediaQuery('(prefers-reduced-motion: reduce)')
const animationClass = motionStyle ? '' : 'animate-spin'

// 错误：过度动画
<button className="animate-bounce transition-all duration-500 hover:scale-150">
  Over animated
</button>
```

## 禁止事项
- 禁止无目的的装饰性动画
- 禁止在滚动时触发动画（影响性能）
- 禁止动画时长超过 500ms
- 禁止阻塞用户交互的动画
