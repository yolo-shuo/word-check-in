# 项目开发日志格式

> 状态：已确认

## 目的
记录每天的开发工作，便于回顾进度、追踪问题、交接工作。

## 适用范围
所有开发人员，每天下班前提交。

## 规范内容

### 日志文件
- 路径：`项目基准/一、术语与文档/logs/`
- 文件名：`YYYY-MM-DD.md`
- 每天一个文件

### 日志结构

```markdown
# 开发日志 - YYYY-MM-DD

## 今日完成
- [x] 完成的功能/修复
- [x] 完成的测试

## 进行中
- [ ] 未完成但已开始的工作

## 明日计划
- [ ] 计划要做的事项

## 遇到的问题
- 问题描述 + 当前状态 + 需要什么帮助

## 备注
其他需要记录的事项
```

### 填写规则
- 已完成项打勾 `[x]`
- 进行中项不打勾 `[ ]`
- 问题必须描述清楚现状和需要的帮助
- 提交 PR 时附上日志链接

## 禁止事项
- 禁止漏填日志
- 禁止只在提交信息中写日志
- 禁止日志只写"今天修了 bug"而无具体内容
