# 术语定义

> 状态：已确认

## 目的
统一项目中关键术语的定义，避免歧义，确保团队成员理解一致。

## 适用范围
全部开发、设计、文档、测试工作。

## 规范内容

### 核心概念

| 术语 | 英文 | 定义 |
|---|---|---|
| 圈子 | Circle | 3-15 人熟人学习小组，由创建者管理，成员共同打卡、互动 |
| 打卡 | Checkin | 用户记录当天学习单词数量与用时，发布到圈子动态流 |
| 草稿 | Draft | 未发布的打卡记录，仅自己可见 |
| 撤回 | Withdraw | 已发布打卡的撤回操作，撤回后不可恢复 |
| 动态流 | Feed | 圈子内打卡记录的聚合展示，按时间倒序排列 |
| 词库版本 | VocabVersion | 词库的一个快照版本，用户可选择不同版本 |
| 词库词条 | VocabEntry | 词库中的单个单词条目，包含词义、例句等 |
| 掌握状态 | Mastery | 用户对某单词的掌握程度，影响复习提醒 |
| 连续天数 | Streak | 连续打卡的天数，用于统计激励 |
| 审计日志 | AuditLog | 记录关键操作的操作日志，用于追踪 |
| 周榜 | WeeklySnapshot | 每周圈子统计快照，用于排行榜 |

### 枚举值定义

| 枚举 | 值 | 说明 |
|---|---|---|
| 打卡状态 | DRAFT | 草稿 |
| 打卡状态 | PUBLISHED | 已发布 |
| 打卡状态 | WITHDRAWN | 已撤回 |
| 掌握状态 | NEW | 新词 |
| 掌握状态 | LEARNING | 学习中 |
| 掌握状态 | REVIEWING | 复习中 |
| 掌握状态 | MASTERED | 已掌握 |
| 圈子角色 | OWNER | 所有者 |
| 圈子角色 | MEMBER | 普通成员 |
| 通知类型 | CHECKIN_PUBLISH | 新打卡 |
| 通知类型 | LIKE_RECEIVED | 收到点赞 |
| 通知类型 | COMMENT_RECEIVED | 收到评论 |
| 通知类型 | MEMBER_JOINED | 新成员加入 |
