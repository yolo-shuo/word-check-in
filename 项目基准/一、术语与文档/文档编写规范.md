# 文档编写规范

> 状态：已确认

## 目的
规范项目文档的编写风格、格式和流程，确保文档清晰、一致、可维护。

## 适用范围
所有 `.md` 文档文件，包括 `AGENTS.md`、`项目基准/` 下的所有规范、以及 `src/` 下的文档。

## 规范内容

### 基本格式
- 使用 UTF-8 编码
- 使用 Markdown 语法
- 标题层级从 `#` 到 `####`，不跳级
- 列表使用无序列表 `-`，有序列表使用 `1.` 递增
- 代码块必须标注语言（如 ` ```ts `、` ```tsx `、` ```prisma `）

### 文件头部
- 每个规范文件第一行为 `# 文件名`
- 第二行空行后为 `> 状态：草案 / 评审中 / 已确认 / 已废弃`
- 每个文件必须包含"变更记录"章节

### 变更记录
- 格式：`| 日期 | 变更内容 | 修改人 |`
- 日期格式：`YYYY-MM-DD`
- 修改人可填 `-` 表示匿名

### 示例风格
- ✅ 正确示例 标注 `✅ 正确` 前缀
- ❌ 错误示例 标注 `❌ 错误` 前缀
- 示例代码必须完整可运行

### 链接
- 项目内文件使用相对路径：`[文档模板](../README.md#文档模板)`
- 外部链接使用完整 URL

### 术语使用
- 首次出现术语时标注英文：`圈子 (Circle)`
- 后续统一使用中文名称
- 以[术语定义.md](./术语定义.md)为准

## 禁止事项
- 禁止在代码注释中定义规则
- 禁止在一个文件中混用多个编号体系
- 禁止使用图片代替文字说明（截图除外）
- 禁止超过 500 行的单个规范文件（考虑拆分）
