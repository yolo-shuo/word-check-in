# 应用标识规范

> 状态：已确认

## 目的
定义应用的基本标识信息，确保部署和配置一致。

## 适用范围
所有环境（开发、测试、生产）的配置。

## 规范内容

### 应用信息

| 属性 | 值 |
|---|---|
| 应用名称 | 社区单词打卡 |
| 英文标识 | word-check-in |
| 版本 | 1.0.0 |
| 描述 | 面向 3-15 人熟人小圈子的学习记录工具 |
| 默认时区 | Asia/Shanghai |
| 语言 | zh-CN |

### 域名配置
- 开发：`http://localhost:3000`
- 测试：`https://test.word-checkin.com`
- 生产：`https://word-checkin.com`

### PWA / 应用图标
- 应用图标：`/icons/icon-192.png`
- 截图：`/icons/screenshot.png`
- Manifest 文件：`/manifest.json`

### 环境变量
| 变量 | 说明 | 示例 |
|---|---|---|
| `DATABASE_URL` | 数据库连接 | `postgresql://postgres:postgres@localhost:5432/wordcheckin` |
| `REDIS_URL` | Redis 连接 | `redis://localhost:6379` |
| `NEXTAUTH_URL` | 应用 URL | `http://localhost:3000` |
| `NEXTAUTH_SECRET` | Auth 密钥 | `your-secret-here` |
| `NEXT_PUBLIC_APP_URL` | 前端应用 URL | `http://localhost:3000` |

## 禁止事项
- 禁止在不同环境使用相同的 secret
- 禁止硬编码 URL
- 禁止使用默认的数据库密码
