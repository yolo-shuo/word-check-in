# TestPage 使用与开发文档

> 状态：草案

## 目的
说明测试页面的使用方式和开发规范，便于调试和测试。

## 适用范围
测试相关页面和调试功能。

## 规范内容

### 说明
- TestPage 是开发阶段的测试页面，不对外提供
- 用于快速验证功能、调试 API
- 建议在发布前移除或隐藏

### 访问方式
- 开发环境：通过特定路由访问
- 生产环境：已禁用

### 开发规范
1. 测试页面只用于开发阶段
2. 不在测试页面编写业务逻辑
3. 测试页面需要标注为"测试专用"
4. 发布前确认测试页面已禁用

### 建议
- 建议将 TestPage 改名为"测试页面.md"
- 考虑移除，改用 Playwright 进行 E2E 测试

## 禁止事项
- 禁止在生产环境启用测试页面
- 禁止在测试页面存储用户数据
- 禁止测试页面与生产代码混合
